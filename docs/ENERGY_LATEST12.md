# 最新一、二阶零输入能量实验（2026-10-24）

本次用最新已验收的一、二阶程序补算六组自由耗散轨迹，并将论文中的一、二阶能量图更新为这批新结果。三、四阶采用前一轮已验收数据，不重新计算。旧的一、二阶数据、原组合图、17组收敛结果及全部原生数据均保留。

## 对齐范围

一、二阶各取K=8、T=0.5、dt=1/16、1/32、1/64，共112步、118条含初值的记录。连续初值逐式沿用三、四阶能量实验的速度、角速度和磁化形状；物理参数全为1，体源、外加磁场和边界输入为零。初始速度是离散无散子空间上的L2投影，角速度和磁化作L2投影，磁势由零外场离散Maxwell–Poisson约束求得，辅助场通过相应弱约束恢复。

冻结核心来自一、二阶各自的 `common_mms_refinement_20261019/src`；两者31个Python文件逐字节相同，且与最后验收的来源哈希一致。此次复制到独立归档并保留全部原核心文件，通过独立输入适配层提供上述能量初值及零源项/边界。投影使用最新核心已有Projection类的L2选项；未使用新构造解的非零边界、驱动或指数时间轨迹。

一阶使用后向Euler；二阶采用单阶段Gauss中点，首步两次固定线性修正，此后为两步历史外推。与旧二阶能量数据使用的Broyden启动有所区别。各阶仍使用其对应空间有限元，不能把统一图解读成固定空间上只比较时间精度。

全部最终作业必须为COMPLETED/0:0且达到T=0.5。验证包含：每一步全残差小于1e-8、齐次边界系数误差小于1e-12、零源项/边界输入、非负耗散、能量不增、逐步缩放平衡残差小于5e-8和累计相对平衡小于1e-7。K2预检覆盖首个常规外推步、两次增广整体系统对照、24/28阶积分对照。先完成两组K8 dt=1/16正式算例并核对资源，再放行剩余四组。

一阶的正确平衡包含额外非负数值耗散：E(n+1)-E(n)+D(n)+N(n)=0。这里D是乘以dt的物理耗散积分，N是后向Euler的步增量能量；二阶以及三、四阶Gauss方法的N为0。新检查单独核对这个零输入平衡，不通过减去自由行残差功使能量缺口消失。

验收中的Maxwell–Poisson一致性指初始离散状态。逐步数据另保留 `endpoint_constraints` 诊断，它将初始弱关系作用于保存的端点/阶段槽位，并不表示所有这些关系在每个时间层精确为零；其中z、varpi属于阶段槽位，不能直接当作端点辅助约束。能量平衡通过也不能替代独立的逐层磁静力约束检验。本补算不新增这类精确保持声明。

首轮K2预检作业47330204、47330209在诊断读取阶段遇到KeyError：驱动错误地用u键读取以压力测试行p命名的速度散度指标。修正字段名后，两组K2预检重新完整通过；不改变任何数学、矩阵或验收阈值。失败现场、原驱动源码快照及其哈希保留；详情在 `driver_validation_history.json`。
