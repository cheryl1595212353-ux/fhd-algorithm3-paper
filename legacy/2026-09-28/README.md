# Historical convergence material (2026-09-28)

These are the former first/second-order convergence data, figures, scripts and experimental TeX sections from commit 92a574ed028bdeb5f3fdac866a413cf50b10ee1b. They use the previous reference problem and dt=1/K, and must not be mixed into the current 17-case table.

The complete buildable old repository and its PDF previews remain in that Git commit and the `archive/pre-17cases-20261023` branch. This folder is a convenient subset for inspection, not a second current paper build. The old TeX preview here is historical; use the complete old commit to compile it with all of its assets.

The archived convergence script can still be read or run against this folder's old `data/results.*` with the original LaTeX plotting dependencies. Current root commands never invoke it. Root energy/application files remain separately available because those experiments are retained in the latest manuscript.
